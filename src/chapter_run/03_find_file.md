# 4.3 找到要改的那一个文件

先问：我改完，别人会在哪里看见？

| 你想改的 | 先打开 |
| --- | --- |
| 网页上的一句话 | `index.html`，或 README 指到的页面文件 |
| 安装和运行说明 | `README.md` |
| 别人怎么参与 | `CONTRIBUTING.md`。没有这个文件，就看 README 末尾 |
| 一个功能怎么实现 | README 里点名的目录。常见是 `src/` |
| 颜色和排版 | `styles.css` 或 README 提到的样式文件 |

Spoon-Knife 的那句英文在 `index.html` 里，上面还有一行注释：`Feel free to change this text here`。作者把要改的位置标出来了。一次只改这个文件里的这一句。`styles.css` 先不动。

看别的项目时，用这个顺序找文件：

1. README 里有没有写「改某个文件」。
2. 没有的话，在仓库页面按 `t`，输入你记得的文件名。
3. 还是没有，就在网页的搜索框搜你想改的那句原文。搜到的文件就是入口。

一次只选定一个文件。这个文件改完、提交完，再找下一个。

## 你现在做

写下两行：

```text
Spoon-Knife 的正文在：index.html
我如果要改这句话，不动的文件是：styles.css
```
