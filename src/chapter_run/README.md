# 第 4 章 看懂一个别人的项目

这一章练眼睛。先看懂一个小仓库怎么运行、改哪一个文件。看懂之前不克隆，也不提 Pull Request。

练习仓库用 [octocat/Spoon-Knife](https://github.com/octocat/Spoon-Knife)。它只有一个网页，适合看结构。它没有 LICENSE 文件，所以只看，不拿来当自己的项目。

| 小节 | 你要会 |
| --- | --- |
| [4.1 先决定能不能动](./01_can_i_use.md) | 用三行记录决定看、改，还是换一个 |
| [4.2 只跑 README 里的命令](./02_run_readme.md) | 认出项目类型，只执行说明里写过的命令 |
| [4.3 找到要改的那一个文件](./03_find_file.md) | 指出改完之后用户能看见的那一个文件 |
