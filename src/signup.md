# 注册账号

没有账号就做不了后面的仓库。这一页做完，你要能登录，并且邮箱已经验证。

1. 打开 [github.com/signup](https://github.com/signup)。
2. 填一个你能打开的邮箱。
3. 设一个只给 GitHub 用的长密码。
4. 用户名只用小写字母、数字和短横线，不能以短横线开头或结尾。它会出现在每个项目网址里，例如 `github.com/这个名字`。被占用了就换一个，不要等别人放弃。
5. 去邮箱里找 GitHub 的验证码或验证链接。垃圾箱也看一眼。页面上的问题选免费方案，其余可以跳过。
6. 登录后，右上角能看见你的头像。再打开 `https://github.com/你的用户名`，能看见你的主页。

邮箱没验证时，建仓库和 Fork 会失败。验证链接 24 小时内有效。过期了就到头像 → **Settings** → **Emails**，点重新发送。

以后页面要求开双重认证，再开。开的时候把恢复码抄到密码之外的地方。

## 你现在做

退出一次，再用用户名和密码登录。进得去，就去 [第 1 章](./chapter_read/README.md)。
