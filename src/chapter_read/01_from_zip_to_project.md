# 1.1 别人的项目怎么变成你的

你要会的事：把别人的项目留一份在自己的账号里，之后还能接着改。

| 你现在的做法 | 手里有什么 | 够不够用 |
| --- | --- | --- |
| 点 Code，再点 Download ZIP | 当时的一包文件 | 不够。作者一更新，你对不上自己改过的地方 |
| 只看 README | 知道它是干什么的 | 还不能改 |
| 点 Fork，或点 Use this template | 你账号下的一份副本 | 这就是现在的目标 |
| 开 Pull Request | 请原作者收下你的修改 | 以后再练 |

副本有两种留法：

| 你想怎样 | 点哪里 |
| --- | --- |
| 改完想交给原作者 | 页面上的 **Fork**。副本记得自己从哪来，之后可以开 Pull Request |
| 想拿来做成自己的项目，页面上有 **Use this template** | 点它。这是你自己的新仓库 |
| 先下到自己电脑里看 | 点 **Code**，复制地址。这叫 Clone，第 3 章再做 |

Fork 只表示你复制到了一份。能不能拿来用，要看有没有 `LICENSE` 文件。没有这个文件，就先不要当成自己的项目。

## 你现在做

打开 [skills/introduction-to-github](https://github.com/skills/introduction-to-github)。

看页面上有没有 Fork。有的话，记住：点下去，仓库会出现在你的账号里。这一节先别点。
