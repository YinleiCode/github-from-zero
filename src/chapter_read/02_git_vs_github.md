# 1.2 Git 和 GitHub

**Git** 在你电脑上，记住每次改了什么。

**GitHub** 是网站，把项目放出来给别人看、讨论、合并。

网页上先认这几个词：

| 词 | 一句话 | 什么时候用 |
| --- | --- | --- |
| 仓库 Repository | 一个项目的网页 | 一个项目一个仓库 |
| README | 首页那篇说明 | 打开先看它，里面写了怎么运行 |
| 提交 Commit | 记下一次修改，并写一句为什么 | 改完一小步就记一次 |
| 分支 Branch | 另开一条线来改 | 想试一个改动时，先开分支 |
| Issue | 问题或待办 | 还没改文件，先把事情写下来 |
| Pull Request | 请别人把你的修改合并进去 | 改完了再用 |
| Fork | 复制一份到你的账号 | 要改别人的项目时 |

别人要看见你改的一个字，顺序是这四步：

1. 你改了文件。
2. 在电脑上提交。这时只有你自己看得到。
3. 推到 GitHub。你的仓库更新了。
4. 要进原作者的项目，再开 Pull Request，等对方合并。

做自己的项目，做到第 3 步即可。推上去只更新你的副本，原项目要等对方合并才会变。
