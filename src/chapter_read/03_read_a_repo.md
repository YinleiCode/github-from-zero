# 1.3 打开仓库先看哪里

按这个顺序看。看完再决定要不要 Fork。

| 顺序 | 看哪里 | 你要回答 |
| --- | --- | --- |
| 1 | 简介和 README | 它是做什么的？怎么跑？ |
| 2 | 文件列表 | 有说明和代码，还是只有一个压缩包？ |
| 3 | LICENSE | 允不允许我改、拿来用？ |
| 4 | 最近一次提交 | 最近还有没有人更新？ |
| 5 | Releases | 作者让我下载的是不是这一版？ |
| 6 | Issues | 我的问题是不是已经有人提过？ |

许可证只记这几条：

| 看到 | 你怎么做 |
| --- | --- |
| 没有 LICENSE | 不要拿来当自己的项目 |
| MIT 或 Apache-2.0 | 可以改、可以用。保留文件里的版权声明 |
| GPL-3.0 | 可以改。你把改过的版本公开时，也要公开代码 |
| README 只写「仅供学习」 | 照这句话做。拿不准就问作者 |

README 如果指定了版本，去 **Releases** 下载。**Code → Download ZIP** 只是网页上现在这份文件，常常不是正式版。

Star 是收藏人数。人多只说明讨论多，不说明在你电脑上能跑。

看完再选：

| 情况 | 怎么做 |
| --- | --- |
| 想把小改动交给原作者 | Fork |
| 想做成自己的，并且有 Use this template | 用模板 |
| 没有许可证 | 换一个项目 |
