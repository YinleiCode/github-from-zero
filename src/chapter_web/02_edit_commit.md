# 2.2 改 README 并提交

提交就是把一次修改记下来，并写一句人能看懂的说明。

1. 在 `my-notes` 里点 **README.md**。
2. 点右上角的铅笔图标。鼠标停上去会显示 **Edit this file**。
3. 把正文换成这三行，名字和日期换成你自己的：

```markdown
# 我的笔记

这是我用来练习 GitHub 的仓库。

今天开始：写成今天的日期
```

4. 点右上角 **Commit changes...**。
5. 上面的框写 `写下项目说明`。下面的框可以空着。
6. 选 **Commit directly to the main branch**。
7. 点 **Commit changes**。

回到仓库首页，能看见这三行。点 **Commits**，能看见一条说明是「写下项目说明」的记录。这次是直接改在 `main` 上，适合第一句说明。后面试改动时，改走分支。

提交说明写「做了什么」。`update`、`修改` 这种词以后的你看不懂。

## 你现在做

再点一次铅笔，加一行 `练习用仓库`，按上面的 4 到 7 步提交。提交说明写成 `补上一行用途`。

Commits 里应该有两条记录。下一步：[2.3 开分支、提 Pull Request、合并](./03_branch_pr.md)。
