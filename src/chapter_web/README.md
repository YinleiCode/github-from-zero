# 第 2 章 在网页上改一次

这一章不装软件。做完，你自己的账号里要有一个仓库，并且有一次通过 Pull Request 合并进去的修改。

仓库名用 `my-notes`。后面几章都接着用它。

| 小节 | 你要会 |
| --- | --- |
| [2.1 建一个仓库](./01_create_repo.md) | 建出带 README 的公开仓库 |
| [2.2 改 README 并提交](./02_edit_commit.md) | 在网页上改字，并留下一句提交说明 |
| [2.3 开分支、提 Pull Request、合并](./03_branch_pr.md) | 把一次修改走完分支、审核、合并 |
