# 6.1 README 写这四段

别人打开仓库，先看 README。四段就够。

在电脑上的 `my-notes` 里改 README.md，或在网页上点铅笔。内容换成下面这样，括号里的字换成你的：

```markdown
# 我的笔记

我用来练习 GitHub 的仓库。里面记录我看过的项目，和我改过的地方。

## 怎么用

打开这个网页就能看。要在电脑上改，先克隆：

    git clone https://github.com/你的用户名/my-notes.git

## 来源

练习步骤来自《从零看懂 GitHub》。
我自己写的内容从这一份笔记开始。

## 许可证

准备用 MIT。使用和修改都可以，保留版权声明。
```

如果项目是从别人的仓库改出来的，「来源」要写成：

```markdown
## 来源

从 https://github.com/原作者/仓库名 改来。
我改了：写明文件名。
原项目的许可证是 MIT，这里保留它的版权声明。
```

没有「来源」和「许可证」这两段，先不要把仓库发给别人。

提交：

```bash
git add README.md
git commit -m "补上用途、来源和许可证说明"
git push
```

在网页上改的，用第 2 章的办法提交，说明写同一句。

## 你现在做

用浏览器的无痕窗口打开你的仓库。不看别的页面，只看 README，能不能回答：这是什么、怎么拿到电脑上、从哪来。三句都能答，这一节就过了。
