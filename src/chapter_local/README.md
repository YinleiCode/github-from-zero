# 第 3 章 放到自己电脑

网页适合改一句说明。项目要在自己电脑上跑，就得把仓库克隆下来。克隆会连同历史一起下载，比 Download ZIP 多一个 `.git` 文件夹。不要删它。

下面的命令在 Mac 和 Windows 的终端里一样。Mac 第一次运行 `git` 时，按提示安装开发者工具。Windows 先安装 [Git for Windows](https://git-scm.com/download/win)，再打开 Git Bash。

| 小节 | 你要会 |
| --- | --- |
| [3.1 安装 Git，克隆仓库](./01_clone.md) | 把 `my-notes` 下载成一个带历史的文件夹 |
| [3.2 改完，提交，推上去](./02_commit_push.md) | 用四条命令把电脑上的修改同步到网页 |
| [3.3 拉取更新，用分支试改动](./03_pull_branch.md) | 接上网页上的新修改，并在分支上试一次 |
