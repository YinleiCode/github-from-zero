# 开始

做完这条线，你就会用 Git 和 GitHub，并有一个能发给别人的项目。

1. [注册账号](./signup.md)，并验证邮箱。
2. [第 1 章](./chapter_read/README.md)：看懂一个仓库。
3. [第 2 章](./chapter_web/README.md)：在网页上建仓库，改一次，合并。
4. [第 3 章](./chapter_local/README.md)：在电脑上克隆、修改、推送。
5. [第 6 章](./chapter_ship/README.md)：写 README 和许可证，用 Pages 发出网址。

第 4 章、第 5 章是选学。主线做完再看：怎么读别人的项目，以及怎么把修改交给原作者。

按钮名称以网页上的英文为准。默认分支如果叫 `master`，就把书里的 `main` 换成 `master`。
